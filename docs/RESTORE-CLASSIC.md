# Возврат исходного интерфейса

Восстановлены оформление v11 и его исходная компоновка: шапка WB, четыре
первоначальные палитры, показатели над рабочими формами, конвейер выдачи,
приёмка и реестр на одной странице. Визуальные исходники взяты из состояния
до редизайна (`8f980b6`, основанного на исходном `7f8f540`).

Современная логика сохранена: атомарные операции, подписи операторов,
очередь офлайн, обработка конфликтов, отчёты, резервные копии и ограничения
доступа. Схема БД, реальные устройства, журнал и пользовательские очереди
этим изменением не редактируются. В v16 вход переведён на ID без PIN отдельной миграцией `id_only_operator_sessions`.

Боковая навигация удалена из видимого интерфейса; дополнительные журналы и
инструменты создателя доступны через меню. Небольшие скрытые элементы
сохранены для совместимости существующего кода с прежней компоновкой.

Черновые концепты ORBIT, «Поток», «Две линии» и «Парк» не подключены к приложению.
Публикация выполняется после одобрения пользователя.
