Переноси сюда только подтверждённые факты и согласованные направления. Для новых дефектов записывай сценарий, ожидаемое поведение и способ проверки на синтетических данных.

Локально исправлены: задержка получения нового состояния на другом посту при конфликте очереди, отсутствие обновления открытой страницы после публикации, подмена точного серийного номера похожим при приёмке и подтверждение замены тем же Enter, который открыл окно. Сценарии добавлены в [Playwright](../tests/terminal.spec.cjs).

15.11.2026 локально исправлены блокировка независимых исходящих операций чужим конфликтом и архивация всей очереди при сверке. Независимая выдача доходит до второго поста, зависимые пакеты ждут сверки, а «Согласование с облаком» архивирует только конфликтные записи. Оба сценария добавлены в [Playwright](../tests/terminal.spec.cjs).

15.11.2026 исправлена зависимость просрочки и времени выдачи от локальных часов. Сценарий с одинаковыми данными и часами минус сутки воспроизводил `18 / 1`; теперь оба поста получают `18`, операции содержат серверное время, а поправка работает после офлайн-перезагрузки и последующего скачка системных часов. Проверка добавлена в [Playwright](../tests/terminal.spec.cjs).

## Пользовательский прогон 14.11.2026

Перечисленные проблемы исправлены локально. Сценарии на синтетических данных входят в штатный браузерный прогон. Для отдельного запуска используй `npm run test:browser -- audit-session.spec.cjs`.
