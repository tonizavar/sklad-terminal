# SCANNER CONTROL

Русскоязычный складской терминал для учёта ТСД и сканеров. Рабочий пост позволяет выдать устройство по скану, принять обратно, заменить, отправить в ремонт, вернуть из ремонта или списать. Реестр показывает текущие состояния. Отчёт за период и выгрузка парка обслуживают разные задачи. Создателю доступен журнал действий сотрудников.

- [Репозиторий tonizavar/sklad-terminal](https://github.com/tonizavar/sklad-terminal)
- [Рабочий сайт на GitHub Pages](https://tonizavar.github.io/sklad-terminal/)
- Базовая версия при настройке рабочего места — `16.0.0`, [ветка main на коммите afc50ad](https://github.com/tonizavar/sklad-terminal/commit/afc50adc3523fa20fdd9a77597025ec931e36b18).

Оператор входит по ID и PIN. При первом входе сотрудник выбирает и повторяет PIN из 6–12 цифр. На посту оператор сканирует ID получателя и устройство для выдачи, а при возврате сканирует устройство в форме приёмки. ID оператора фиксирует автора, ID получателя связывает устройство с сотрудником. При временной потере сети уже открытый пост сохраняет операции локально в пределах срока действующей сессии.

Статический сайт загружается без сборки. В браузере хранятся рабочие данные и очередь синхронизации. Общий парк, аудит и резервные снимки хранятся в PostgreSQL Supabase. Для разработки используй синтетические данные и [локальные тесты](WORKFLOW.md).
