# Порядок внедрения

Актуальная версия использует ID оператора и личный PIN. Выполняйте [порядок перехода на учёт операторов](OPERATOR-AUDIT.md#внедрение). Предыдущий общий режим без входа был промежуточной версией и больше не является целевой конфигурацией.

Старые очереди нужно сохранить и сверить; не очищайте IndexedDB. Создание реального PIN выполняет владелец в форме первого входа. Одноразовый ключ не публикуется в GitHub, логах и снимках интерфейса.

Старые таблицы warehouse_* не используются этим клиентом; их потребители и права требуют отдельной проверки. Исторические Git-коммиты могут содержать прежний слепок парка; обычная публикация не удаляет сторонние и исторические копии.
